# Clean prose guard

This file uses plain technical English with no LLM clichés. The checker must
report it 100% clean.

The tool reads the file and writes one report per run. Start the agent with
`agent run`. The connection is dead when the peer stops sending packets.

Prefix the variable name with an underscore. The value is the whole number part
of the duration. The command just prints the version. Open the port in the
console before you run the job.

The report lists errors, including timeouts. The team notes every outage in the
log. The analyst reviews the report each week.

The default settings are safe for one node. The library works without external
packages. The parser accepts UTF-8, UTF-16, and ASCII input.

Look at the log before you restart. The look command shows file metadata. Do not
set it manually. Set it in the configuration file.
